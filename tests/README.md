# Автотесты

```
npm test              # все 26 вариантов, ~4 мин на 2 ядрах
node tests/run.js 4 14  # только указанные варианты
npm run test:update   # принять текущие размеры и число наложений как эталон
```

Что проверяется по каждому варианту:
- строятся все листы и спецификации, без исключений; есть обязательные листы (СБ, общий вид, эскиз, рама/вал барабана, корпус);
- если проверочные расчёты изменили размеры — есть эскиз «до проверок»;
- межосевые расстояния на СБ и чертеже корпуса — точно как в расчёте и с допуском (не округлены);
- на листах нет символов, которых нет в шрифте ГОСТ (верхние индексы);
- наложений (по встроенному линтеру) не больше, чем в эталоне;
- все размеры на листах совпадают с эталоном `baseline.json` — любое изменение показывается списком «было / стало»;
- режим «без размеров» убирает размеры и сбрасывает флаг после построения.

Файл `.github/workflows/test.yml` запускает `npm test` на GitHub при каждом изменении — если проект лежит на GitHub.
